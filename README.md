# Line Tracer Project

## 프로젝트 개요

본 프로젝트는 적외선 센서를 이용하여 검은색 라인을 검출하고, Arduino Nano를 통해 모터를 제어하여 자율 주행이 가능한 라인트레이서를 구현한 졸업작품이다.

## 개발 목표

- 검은색 라인 검출 기능 구현
- 직선 및 곡선 구간 주행 구현
- 좌회전 및 우회전 제어 구현
- 라인 재탐색 알고리즘 구현

## 사용 부품

- Arduino Nano
- 적외선 센서 모듈 (SZH-SSBH-006)
- L9110S 모터 드라이버
- KR-300 DC 모터
- 볼 캐스터

## 주요 기능

- 적외선 센서를 이용한 라인 검출
- 직선 주행
- 좌회전 및 우회전 주행
- 라인 미검출 시 재탐색 기능
