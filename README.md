# 라인 트레이서 프로젝트

## 프로젝트 개요
적외선 센서를 이용하여 검은색 라인을 검출하고
Arduino Nano를 이용해 모터를 제어하는
라인 트레이서 시스템 구현

## 사용 부품
- Arduino Nano
- SZH-SSBH-006 적외선 센서
- L9110S 모터 드라이버
- KR-300 DC 모터

## 주요 기능
- 라인 검출
- 직진 주행
- 좌회전 및 우회전
- 라인 재탐색 알고리즘

## 개발 환경
- Arduino IDE
